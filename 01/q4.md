Express is a framework built on top of node.

Once a user sends a request to my express server, node hands it over to express.
Express then creates 2 objects, request and response usually shortened to req,
res. My server tries to match the route.

If the route is valid, the appropriate handler kicks in and handles the request
and sends back a response. If there is no handler for the request express will
send an error response usually a simplet plain text 404 error back to the user.
If it didn't send the response the request will hang and eventually timeout

In this very server, the valid routes would be GET requests to /hello,
/users/:id - where :id is an ID of a user, /search - this route accepts and
utilizes queries specifically a query named q which represents the search term
the user wants to search for.
